# LandarevAI - Чат с искусственным интеллектом

## 📋 Описание

LandarevAI - это веб-приложение чата с искусственным интеллектом, использующее OpenRouter API для генерации ответов. Приложение построено на FastAPI и предоставляет современный интерфейс для общения с AI-ассистентом с поддержкой форматирования Markdown.

## ✨ Особенности

- **Чат с AI**: Интеграция с OpenRouter API для генерации ответов
- **Markdown поддержка**: Автоматическое форматирование ответов AI (заголовки, списки, код, ссылки и т.д.)
- **Современный интерфейс**: Тёмная тема с анимированными элементами
- **Индикатор печати**: Визуальное уведомление о процессе генерации ответа
- **История сообщений**: Сохранение всех сообщений во время сессии
- **Адаптивный дизайн**: Поддержка мобильных устройств

## 🛠️ Технологии

- **Backend**: FastAPI, Python
- **AI API**: OpenRouter (с поддержкой reasoning)
- **Frontend**: HTML, CSS, JavaScript
- **Шаблонизация**: Jinja2
- **Markdown**: Python-Markdown (сервер), Marked.js (клиент)
- **Безопасность**: Bleach для санитизации HTML

## 📦 Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Land1n/LandarevAI.git
cd LandarevAI
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` в корневой директории и добавьте ваш API ключ:
```env
OPENROUTER_API_KEY=ваш_ключ_api
```

## 🚀 Запуск

```bash
uvicorn main:app
```

Приложение будет доступно по адресу: `http://localhost:8000`

## 🔧 API Эндпоинты

- `GET /api` - Получение ответа от AI
  - Параметр: `message` (строка запроса)
  - Возвращает: JSON с ответом

- `POST /send` - Отправка сообщения в чат
  - Параметры: `username`, `text`
  - Возвращает: `{"status": "ok"}`

- `GET /messages` - Получение всех сообщений
  - Возвращает: JSON массив сообщений

- `GET /` - Главная страница чата

## 🎨 Особенности интерфейса
