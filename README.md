# 🤖 LandarevAI

**LandarevAI** — это веб-приложение на базе FastAPI, которое предоставляет интерфейс чата с искусственным интеллектом (через OpenRouter API), а также CRUD-эндпоинты для управления сообщениями и ролями в тестовой базе данных. Проект использует SQLModel для работы с БД, Jinja2 для шаблонов и статические файлы для стилей и клиентской логики.

---

## 🚀 Возможности

- Чат с AI-моделью (интеграция с OpenRouter)
- Отображение сообщений с поддержкой Markdown
- Тестовое REST API для работы с сообщениями (только в режиме DEBUG)
- Страница обработки ошибок с автоматическим перезагрузом
- Современный адаптивный интерфейс (тёмная тема)

---

## 🛠 Технологии

- **Backend**: FastAPI, SQLModel, Pydantic, OpenRouter API
- **Frontend**: HTML, CSS (кастомные), JavaScript (vanilla), Marked.js
- **База данных**: SQLite (по умолчанию), поддерживается любая SQLAlchemy-совместимая БД
- **Шаблонизация**: Jinja2
- **Зависимости**: управление через `pip` + `venv`

## ⚙️ Установка и запуск

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/your-username/Landarev-AI.git
   cd Landarev-AI
   ```

2. **Создайте виртуальное окружение и активируйте его:**

   ```bash
   python -m venv venv
   source venv/bin/activate   # Linux/Mac
   # или
   venv\Scripts\activate      # Windows
   ```

3. **Установите зависимости:**

   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте переменные окружения** – создайте файл `.env` в корне проекта и укажите:

   ```env
   DATABASE_URL=sqlite:///./test.db
   OPENROUTER_API_KEY=your_api_key_here
   OPENROUTER_API_BASE_URL=https://openrouter.ai/api/v1
   DEBUG=True   # или False для продакшена
   ```

5. **Запустите приложение:**

   ```bash
   uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
   ```

6. Откройте браузер и перейдите по адресу: [http://localhost:8000](http://localhost:8000)

## 📌 Доступные эндпоинты

### Основные страницы

| Метод | URL          | Описание                           |
|-------|--------------|------------------------------------|
| GET   | `/`          | Перенаправляет на `/chat`          |
| GET   | `/chat`      | Страница чата с AI                 |
| GET   | `/error`     | Страница ошибок (параметр `?code=`)|

### API (AI)

| Метод | URL                         | Описание                                  |
|-------|-----------------------------|-------------------------------------------|
| GET   | `/api/v1/ai/?message=...`   | Отправляет запрос к OpenRouter и возвращает ответ AI |

### Тестовое API (работает только при `DEBUG=True`)

Префикс: `/api/v1/test`

| Метод   | URL                         | Описание                           |
|---------|-----------------------------|------------------------------------|
| GET     | `/message`                  | Получить все сообщения             |
| GET     | `/message/{message_id}`     | Получить сообщение по ID           |
| POST    | `/message`                  | Создать новое сообщение (JSON)     |
| PUT     | `/message/{message_id}`     | Обновить сообщение по ID           |
| DELETE  | `/message/{message_id}`     | Удалить сообщение                  |

> **Примечание:** Все тестовые эндпоинты возвращают JSON вида `{"result": ...}`.

## 🗄 База данных

По умолчанию используется SQLite (`test.db`). При первом запуске таблицы создаются автоматически (через `create_db_and_tables()` в роутере чата).

Для использования другой СУБД (PostgreSQL, MySQL) измените `DATABASE_URL` в `.env`.

---

## 🎨 Интерфейс

- Чат автоматически переключается в режим истории после первого отправленного сообщения.
- Сообщения от AI отображаются с поддержкой Markdown (жирный, курсив, списки, код и т.д.).
- Индикатор печати и адаптивная вёрстка для мобильных устройств.

---

## 🧪 Разработка и отладка

- Для включения тестового API установите `DEBUG=True` в `.env`.
- Для просмотра ошибок используйте страницу `/error?code=XXX`.
- Логи SQL-запросов выводятся в консоль благодаря `engine = create_engine(..., echo=True)` – отключите в продакшене.
